# Keala final-connection-candidate：Hello World 同机 A/B

- 时间：2026-11-01 13:24:01 → 2026-11-01 13:24:52（Asia/Singapore，UTC+8）。
- 机器：Apple M4，10 逻辑 CPU，16 GiB，darwin arm64。
- 运行时：Node 26.9.0、Bun 1.4.4；编译器 TypeScript 7.0.2；srvx 1.0.8；autocannon 8.0.0。
- 实测运行时：node；负载客户端始终使用 Node。
- 负载：200 个总连接，4 个独立 Node 客户端进程，HTTP/1.1 keep-alive，pipelining=1。每样本预热 1 秒，测量 5 秒；每运行时 4 对 A/B。
- 每次使用全新的服务端进程。仅注册 GET /，返回 Hello World；无中间件、无 pooling、无 sink。两份源码使用同一套编译配置和依赖构建成 JS；测量中不运行 TypeScript 编译器或类型剥离器。
- 每轮把同一运行时的 before / after 背靠背测量，奇偶轮交换先后；运行时首发顺序也轮换。只对计时无效的一整对样本重试，不按快慢筛选样本。
- CPU/请求 = 服务端进程 user+system CPU 增量 / 客户端已完成请求数，单位 ns/req，包含传输、路由、处理器、GC 等进程 CPU；不包括负载客户端 CPU。冷 IPC 快照在预热后和测量结束后读取，窗口包含开始屏障及客户端收尾，不能当作单独 handler 的 CPU 时间。
- 吞吐由完成请求数除以实际客户端窗口计算；延迟来自合并后的毫秒量化直方图，0 不表示零延迟，平均值的小数也不代表微秒精度。表格为各样本统计量的中位数，变化为同轮 after/before 比值的中位数，两者不能混为一谈。
- 主机一分钟负载（样本前后）范围 2.62–4.66；客户端最高单核 CPU 47.3%。
- 严格计时校验导致 0 对被拒绝并整对重测，原因和被拒绝的已完成样本保存在 results.json。响应错误、超时、非 2xx、正文不匹配不重试。
