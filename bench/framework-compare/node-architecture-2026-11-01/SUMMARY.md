## 证据与边界

[最终 Node 完整报告](node-final/REPORT.md)、[原始 JSON](node-final/results.raw.json.gz)、[远程核验](node-final/verification-node-final.json)、[构建 manifest](manifest-final.json)。156 样本、88 预检、3,214,881 请求；无错误、超时、非 2xx、正文不匹配或计时拒绝；320 个已记录子进程全部退出。原服务 PID 未变、OOM 计数为 0；内存峰值 149.70 MiB，最小可用内存 1346.46 MiB。

全部样本受到 CPU 配额节流；客户端也在同一配额内竞争，延迟为毫秒精度。因此结果用于同等预算下比较，不能当作峰值容量。

[先前完整 Node/Bun 矩阵](REPORT.md) 使用 `6f20` 候选，共 312 样本。最终版只修正原生 Node 冷关闭，Bun 已执行代码不变，保留该次 Bun 1.4.4 对照；三个框架的十二路由吞吐汇总相差不足 0.6%，CPU 与延迟也未全面领先。两轮原始数据均保留。

[实现与架构裁决](../../../docs/NODE-PERFORMANCE.md)：连接级 drain、延迟取消监听、稳定分发函数、响应默认对象与 URL 扫描优化；路由原型和响应头原型均因无收益被撤销。完整 Node/Bun 测试、覆盖率、Node 20.19.5 兼容、构建、四项进程检查、运行时合同和两种内存 soak 均通过。
